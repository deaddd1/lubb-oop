Капстоун-проєкт: RestaurantSystem (Варіант №6)
📌 Опис проєкту
RestaurantSystem — це модульний застосунок для автоматизації внутрішніх бізнес-процесів сучасного ресторану (керування замовленнями, динамічним меню, аналітикою та розрахунками столів). Проєкт розробляється ітеративно як єдиний навчальний капстоун в межах курсу ООП, де кожна наступна лабораторна робота розширює попередній інкремент.

🚀 Поточний статус: Ітерація 1 (Лабораторна робота №34)
На першому етапі розгорнуто стабільний архітектурний каркас та реалізовано базовий бізнес-сценарій:

Clean Architecture: Чіткий розподіл системи на ізольовані шари (Domain -> Application <- Infrastructure <- Console).

Доменне ядро: Створено сутності Order, OrderItem та ієрархію позицій меню (DishItem, DrinkItem) з повною інкапсуляцією та валідацією внутрішнього стану.

Вертикальний зріз (Vertical Slice): Реалізовано повний наскрізний шлях: Консоль -> Сервіс застосунку -> Доменні правила -> In-Memory сховище -> Друк чека.

Тестування: Логіку обчислень та захист інваріантів покрито автоматичними юніт-тестами (xUnit).

CI/CD: Налаштовано автоматичний робочий процес через GitHub Actions для перевірки збірки та тестів при кожному пуші.

🛠️ Інструкція із запуску та перевірки
Щоб скомпілювати, протестувати або запустити проєкт через термінал, використовуйте стандартні команди .NET CLI:

1. Компіляція рішення
Перевірка проєкту на відсутність синтаксичних помилок:

Bash
dotnet build RestaurantSystem.sln
2. Запуск автоматичних тестів
Запуск 5 юніт-тестів, які перевіряють бізнес-правила (ціни, кількості, блокування оплачених чеків):

Bash
dotnet test RestaurantSystem.sln
3. Запуск консольного інтерфейсу
Запуск демонстраційного сценарію (відкриття столу №5, додавання українського борщу та соку, підрахунок суми та закриття чека офіціантом):

Bash
dotnet run --project src/RestaurantSystem.Console/RestaurantSystem.Console.csproj
📂 Архітектурна структура репозиторію
src/RestaurantSystem.Domain/ — Серце системи. Містить чисті сутності предметної області, логіку інваріантів, приклади поліморфізму та абстрактні контракти для сховищ (IOrderRepository). Абсолютно незалежний шар.

src/RestaurantSystem.Application/ — Шар сервісів прецедентів (Use Cases). Оркеструє роботу домену, координує виконання операцій замовлення та оплати.

src/RestaurantSystem.Infrastructure/ — Шар інфраструктури. На поточній ітерації реалізує швидке In-Memory сховище даних на базі колекцій Dictionary.

src/RestaurantSystem.Console/ — Шар користувацького інтерфейсу. Консольне меню для взаємодії з персоналом та виведення логів роботи.

tests/RestaurantSystem.Tests/ — Проєкт автоматичного тестування бізнес-логіки.
